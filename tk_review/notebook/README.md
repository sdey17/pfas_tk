# Notebook bundle

Self-contained. Copy this folder anywhere; it needs **matplotlib and the
Python standard library only** — no pandas, no project imports, no
installs.

| File | What it is |
|---|---|
| `albumin_plots.ipynb` | the three figures, runnable top to bottom |
| `albumin_plots.py` | the same code as a flat script, for a terminal |
| `albumin_logK_Kd_revised.csv` | the Coefficients sheet, 285 rows |
| `albumin_logK_Kd_revised_notes.csv` | the Notes sheet — read it before quoting a number |

`../albumin_logK_Kd_revised.xlsx` is the same data as a workbook.

Both code files are generated by `../scripts/build_notebook.py`, from one
set of cell sources, so they cannot drift apart. Edit that script, not
these, if a change should survive a rebuild:

    python3 -I ../scripts/export_notebook_bundle.py   # refresh the CSVs
    python3 -I ../scripts/build_notebook.py           # rebuild the .ipynb
    python3 -I ../scripts/build_notebook.py --py      # rebuild the .py

## One caveat worth repeating

"Qin 2024" is the baseline-toxicity paper (doi 10.1021/acs.est.3c09950),
Table 1. Each of its values is a Freundlich fit read at IC10,free — one
high loading, 0.3 to 12 PFAS per albumin. A second Qin 2024 paper reports
the same fits at a different concentration, up to 1.44 log higher. Never
quote one of these numbers without the concentration it belongs to.
